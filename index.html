01 / THE CHALLENGE

MENGAPA INOVASI INI DIBUTUHKAN?

Ketika alam indah,
keselamatan tetap utama.

Pendakian gunung menghadirkan tantangan berupa medan ekstrem, perubahan suhu, risiko terjatuh, dan kemungkinan tersesat. Situasi menjadi lebih sulit ketika pendaki berada di wilayah yang tidak terjangkau sinyal seluler.

Dalam kondisi darurat, pendaki mungkin tidak mampu menggunakan ponsel untuk meminta bantuan. Karena itu, diperlukan rancangan perangkat yang dapat mendeteksi indikasi bahaya dan membantu mengirimkan koordinat lokasi secara otomatis.

SMART CLIMBERS COMPANION

Bukan sekadar alat.
Teman keselamatan.

Smart Climbers Companion adalah rancangan perangkat wearable berbasis Internet of Things (IoT) yang terintegrasi pada chest harness pendaki.

Sistem ini menggabungkan sensor gerak, sensor suhu, GPS, dan komunikasi LoRa untuk mendukung deteksi otomatis indikasi bahaya serta pengiriman koordinat darurat ke unit penerima di basecamp.

✓ Deteksi indikasi bahaya otomatis
✓ Pelacakan koordinat GPS saat darurat
✓ Komunikasi radio tanpa jaringan seluler
✓ Rancangan hemat daya

02 / CORE FEATURES

Dirancang untuk
menghadapi keadaan darurat.

Setiap fitur dirancang untuk membantu mengenali indikasi bahaya dan mendukung proses pencarian pendaki.

⌁ FEATURE 01

Automatic Fall Detection

Sensor IMU Bosch BMI160 membaca perubahan gerak dan percepatan. Ketika pola gerak memenuhi kriteria deteksi jatuh yang ditentukan, sensor dapat memicu mikrokontroler melalui hardware interrupt.

01
❄ FEATURE 02

Temperature Monitoring

Sensor DS18B20 memantau suhu pada area dada atau kerah. Rancangan menggunakan ambang suhu di bawah 30°C selama 15 menit berturut-turut sebagai pemicu peringatan indikasi hipotermia.

DS18B20 · 1-WIRE
⌖ FEATURE 03

Emergency GPS Tracking

Saat kondisi darurat terdeteksi, GPS u-blox NEO-6M diaktifkan untuk memperoleh koordinat lokasi yang kemudian disiapkan untuk dikirimkan.

U-BLOX NEO-6M
⌁ FEATURE 04

Off-Grid Communication

Modul LoRa SX1278 pada pita 433 MHz dirancang untuk mengirimkan paket darurat berisi identitas perangkat dan koordinat menuju gateway di basecamp, tanpa bergantung pada jaringan seluler.

LORA · 433 MHz
ϟ FEATURE 05

Smart Power Management

Sistem dirancang untuk mengutamakan mode tidur ketika tidak ada keadaan darurat. Sakelar daya MOSFET P-Channel Si2301 memutus suplai GPS ketika tidak digunakan untuk membantu menghemat energi.

LOW POWER
ENERGY EFFICIENT DESIGN

04 / TECHNOLOGY INSIDE

Teknologi di balik
Smart Climbers Companion.

Komponen dipilih dengan mempertimbangkan konsumsi daya, ukuran, fungsi, dan kebutuhan lingkungan pendakian.

CPU PROCESSING

Pro Micro nRF52840

Mikrokontroler utama yang memproses data sensor, menjalankan logika darurat, dan mengatur komunikasi antarkomponen.

Fokus: ultra-low-power
IMU MOVEMENT

Bosch BMI160

Sensor inersia 6-DoF untuk membaca percepatan dan gerakan serta mendukung pemicu deteksi jatuh.

Interface: I²C
°C TEMPERATURE

DS18B20

Sensor suhu digital yang ditempatkan di area dada atau kerah melalui kabel ekstensi.

Interface: 1-Wire
GPS POSITIONING

u-blox NEO-6M

Modul penerima satelit untuk memperoleh koordinat lokasi saat proses darurat berlangsung.

Interface: UART
RF COMMUNICATION

LoRa SX1278

Modul radio untuk mengirim paket data berukuran kecil ke gateway di basecamp melalui pita 433 MHz.

Interface: SPI
BAT POWER

Baterai Li-ion 21700

Sumber daya utama dengan kapasitas yang direncanakan sekitar 4.000–5.000 mAh untuk mendukung operasional perangkat.

Power gating: Si2301

06 / BUILT FOR THE OUTDOORS

Ringkas, tangguh,
dan terintegrasi.

Perangkat dirancang agar dapat dipasang pada chest harness tanpa mengganggu gerakan pendaki. Sensor suhu ditempatkan terpisah menuju area dada atau kerah untuk pemantauan suhu.

01

PA-CF — Outer Shell

Nylon yang diperkuat serat karbon sebagai material cangkang luar dengan fokus pada kekuatan dan ketahanan gesekan.

02

TPU 95A — Shock Absorber

Material fleksibel yang dirancang sebagai bumper untuk membantu meredam benturan.

03

Integrated Harness

Penempatan modul utama pada harness dan sensor suhu pada area tubuh yang ditentukan.
